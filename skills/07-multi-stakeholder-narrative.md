# SKILL: Multi-Stakeholder Narrative & Cognitive Ergonomics

## Trigger / When to Use
Use when formatting final controlling insights for different organizational audiences.

## Instructions
1. **Apply Three-Tier Structure**:
   - **Tier 1 (Executive Snapshot)**: 3–4 primary KPI cards, macro variance summary, 5-second rule layout.
   - **Tier 2 (Managerial Analysis)**: Variance bridge charts, category breakdowns, monthly trendlines.
   - **Tier 3 (Operational Detail)**: Granular transaction tables, root-cause drill-downs.
2. **Cognitive Ergonomics & Visual Contrast**:
   - Maintain 90% muted baseline styling with single focal accent color for anomalies.
   - Ensure WCAG AA contrast ratio (>4.5:1).
3. **Draft Narrative**: Write concise, action-oriented executive summaries.

## Constraints
- Never present unformatted data dumps to executive stakeholders.
