# SKILL: Prognostic Predictive Modeling

## Trigger / When to Use
Use when projecting future financial trajectories, run rates, and risk-adjusted scenarios.

## Instructions
1. **Select Baseline Model**: Apply time-series trend extrapolation (moving average, exponential smoothing, or linear regression).
2. **Construct 3 Scenarios**:
   - **Conservative**: Lower-bound confidence interval with adverse cost assumptions.
   - **Base Case**: Expected trend continuation.
   - **Aggressive**: Upper-bound trajectory with full benefit realization.
3. **Quantify Risk & Sensitivity**: Identify key swing variables and estimate financial exposure.

## Constraints
- Always present prediction intervals / confidence bands alongside point estimates.
