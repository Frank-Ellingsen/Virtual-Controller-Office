# SKILL: Prescriptive Strategy & Action Matrix

## Trigger / When to Use
Use when formulating strategic recommendations and corrective actions based on diagnostic findings.

## Instructions
1. **Develop Actionable Recommendations**: Formulate 3 distinct corrective interventions.
2. **Score Strategy Matrix**: Evaluate each recommendation across:
   - **Financial ROI / Cost Impact** ($ saved or gained)
   - **Implementation Effort / Time-to-Value** (Weeks/Months)
   - **Operational Risk Rating** (Low/Med/High)
3. **Formulate Prescriptive Decision Card**: Rank options and state clear trade-offs for HITL decision-making.

## Constraints
- Every recommendation must include an estimated cost-to-implement and expected payback timeline.
